Tap a tile to load it into the big pane. Everything you need to fix a reference — blur it, paint an area out, compare before/after — happens there, on the picture itself, instead of in a form beside it.

Already in the pack (just needs this home)

  • Per-picture face blur: auto (blur unless it is the ID photo) / always / never.
  • Blur area grow around the detected head: hair / face only / whole head.
  • Hand-painted areas - normalized strokes, saved with the workflow: this is how you take out an object, a logo, a tattoo or a second person, not only a face.
  • Before/after compare of exactly what the render wires.
  • Video and audio reference slots (3 each) with roles.

The one real gap

  • Video references cannot be blurred today - only pictures. If you take identity from a picture but motion from a clip whose performer should not leak in, there is currently no way to blur that clip.
  • Same for a region of a video (blur frames 20-60 only).
  • Audio needs no blur; what it wants is a trim/waveform view, which the plan already has for the export side.

What it would take

  • Video blur: per-frame detection is the expensive part - the honest version is detect on a sample of frames, propagate the box, blur every frame, cached next to the file like the picture blur already is.
  • Paint on video: paint once on a keyframe, hold it across the window (my suggestion: box-based, not pixel-based, so it stays cheap and predictable).
  • Both are engine work (face_blur.py), not panel work - the mockup above is what the panel would show either way.

What stays exactly the same

  • Every payload key and the node's widgets - this is presentation only.
  • All current controls, just drawn differently (nothing is removed).
  • The preset ids, the resolution chips' rules, the suite's board list.
  • Tests: the payload/spec suites stay green; the panel's DOM tests get updated selectors.

My recommendation

  • A first: it removes both dropdowns and the hint bar in one pass, and it is where the glyph vocabulary pays off most.
  • Then take B's big preview as the top of the Results tab (not the whole panel).
  • Keep C's tile wall as the preset gallery behind a "Browse" button.

Phase 2 (the real win)

  • Use your own last render of each layout as the card art - the folder already keeps every sheet on disk.
  • Then "which sheet do I want" is answered by a picture of the sheet you got last time.
  • Same for references: show the actual reference face as an avatar instead of a filename.
